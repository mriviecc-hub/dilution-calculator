# dilution-calculator
## Plot Grid

`plot-grid/index.html` is a standalone story-planning grid (in the style of Scrivener/Plottr plot grids). Open it in any browser — no build step.

- Rows are plotlines (color-coded), columns are chapters/beats (with an optional act label). Swap axes from the **More** menu.
- Click an empty cell to add a scene card; click a card to edit title, notes, status and tags, or move it to another cell.
- Drag cards between cells (swaps if occupied); drag the ⠿ handle or use the arrows to reorder rows/columns.
- Multiple projects, undo/redo (Ctrl+Z / Ctrl+Shift+Z), filter by text or status (`/` focuses search), compact mode, light/dark.
- Saved automatically in the browser's localStorage. Export JSON (backup/import), Markdown outline, or CSV.
